You are a document block classifier for scanned exam papers.

You will be given an image crop of a single block from a CBT (Computer Based Test) question paper.

Your task:
1. Classify this block into exactly one of the following types:
   - text: Plain prose text, extractable from text layer
   - math_inline: Mathematical expression embedded within a text line
   - math_block: Standalone mathematical expression or equation on its own line(s)
   - matrix: A matrix or vector expression (standalone math containing array/matrix structures)
   - image: Embedded raster figure (graph, diagram, chart, etc.)
   - table: Tabular data with rows and columns
   - metadata_field: A key-value line printed by the CBT platform (e.g. "Question Type : MCQ")
   - question_header: The bold header line identifying question ID, type, and marks
   - option_block: An MCQ/MSQ option (text or image)
   - answer_block: Answer key / possible answers section
   - section_header: Section or sub-section heading
   - page_artifact: Page numbers, headers, footers — to be discarded

2. Rate your confidence: high (certain), medium (minor ambiguity), or low (significant ambiguity).

3. If the block contains mathematical notation, describe what kind (equation, matrix, vector, expression, etc.).

Return a JSON object with exactly these fields:
{
  "block_type": "<one of the types listed above>",
  "confidence": "high | medium | low",
  "has_math": true | false,
  "math_description": "<optional: what kind of math if has_math is true>",
  "notes": "<optional string describing any ambiguity>"
}

Return only the JSON object. No explanation, no preamble.
